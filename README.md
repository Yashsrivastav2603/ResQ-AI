# ResQ-AI
AI Disaster Response & Resource Allocation — React/HTML/CSS/JS frontend + backend integration starter.

Frontend: HTML5, CSS3, JavaScript ES6+, React + Vite, React Router, Leaflet-ready.
Backend integration: FastAPI + PostgreSQL-ready.

Run:
cd frontend
npm install
npm run dev

Team:
- Frontend + AI integration: frontend/
- Backend + database: backend/
